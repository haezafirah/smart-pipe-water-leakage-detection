# User Stories

1. As a maintenance technician, I want to receive an alert as soon as a possible leak is detected, so that I can repair the pipe before musch water is wasted.
2. As a water utility manager, I want to see live flow and pressure readings on a dashboard, so that I can check the pipe condition without visiting the site.
3. As a system administrator, I want view historical readings for a chosen date range, so that I can analyse leak patterns and find weak points in the pipe network.
